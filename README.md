# Patrick Taylor

Applied Mathematics and Computer Engineering, Queen's University.

I build small tools that check their own output. Several of the projects below refuse
to print a claim they cannot trace back to a source, whether that source is a field in
a regulatory filing, a page in a scanned document, or a row in a database. My research
is in q-deformed mathematics, under an NSERC USRA at Queen's.

## Projects

| Project | What it does | Link |
|---|---|---|
| [whale-agent](https://github.com/patrickt6/whale-agent) | Ingests public investment disclosures across SEC Form 4/13D-G, Japan EDINET and Taiwan MOPS, normalizes them to USD, scores them against a configurable threshold, and emits a daily table and a weekly research note. Drops any sentence whose figure does not trace to a filing field. MIT licensed. | [whale-agent.com](https://whale-agent.com) |
| [stable-sharpe](https://github.com/patrickt6/stable-sharpe) | Walk-forward backtest comparing a Black-Litterman portfolio against mean-variance optimization on 10 S&P 500 sector ETFs. Backtest Sharpe ratio 0.86 vs. 0.64, with a 41% smaller max drawdown. Backtest results, not realized returns. | Repo, and a [live dashboard](https://stable-sharpe.streamlit.app) |
| Understudy | A study tutor that answers questions from a student's own course files. Every citation passes a deterministic gate: it is rejected unless the cited page exists, is in range, and contains the quoted text verbatim. Built under Carrell Labs. | Private, no public deploy |
| Roleweave | A local-first careers tracker for postings, applications, events and contacts. Its resume renderer only prints claims that trace to evidence on file. | Private, no public deploy |
